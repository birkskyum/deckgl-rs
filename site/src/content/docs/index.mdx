## The crates

Three crates in one workspace, mirroring the three vis.gl libraries they are ported from.
Each builds on the one above it.

<CardGrid>
  <LinkCard
    title="mathgl-rs"
    href="/visgl-rs/api/mathgl/"
    description="Port of math.gl. Web Mercator projection and camera math in f64: viewports, view and projection matrices, and the coordinate systems the layers position against."
  />
  <LinkCard
    title="lumagl-rs"
    href="/visgl-rs/api/lumagl/"
    description="Port of luma.gl. The rendering layer on wgpu: shader assembly from modules, uniform blocks, textures and samplers, Model, and headless device helpers."
  />
  <LinkCard
    title="deckgl-rs"
    href="/visgl-rs/api/deckgl/"
    description="Port of deck.gl. Deck, Layer and Viewport, the project shader module, Arrow data accessors, and the render loop that draws into a pass you own."
  />
</CardGrid>

The layer catalogue and the JSON API live in `deckgl-rs-layers` and `deckgl-rs-json`, in the
[full API reference](/visgl-rs/api/).

## Getting started

```sh
git clone https://github.com/birkskyum/visgl-rs
cd visgl-rs
cargo run --release --bin window          # the example scene, in a window
cargo run --release --bin json_render -- examples/json/shadows.json out.png
```

```rust
use deckgl::{Accessor, Deck, DeckProps, LayerData, LayerProps, ViewState};
use deckgl_layers::{ScatterplotLayer, ScatterplotLayerProps};

let layer = ScatterplotLayer::new(ScatterplotLayerProps {
    base: LayerProps::new("points"),
    data: LayerData::from_batch(record_batch),   // an Arrow RecordBatch
    get_position: Accessor::column("geometry"),
    get_fill_color: Accessor::column("color"),
    get_radius: Accessor::Constant(50.0),        // metres
    ..Default::default()
});

let mut deck = Deck::new(&device, &queue, target, DeckProps {
    width, height,
    view_state: ViewState { longitude: -122.4, latitude: 37.8, zoom: 12.0, pitch: 45.0, bearing: 0.0 },
    layers: vec![Box::new(layer)],
    ..Default::default()
})?;
deck.render(&mut encoder, &color_view, Some(&depth_view), Some(wgpu::Color::TRANSPARENT))?;
```

This is an independent project by [Birk Skyum](https://github.com/birkskyum), not affiliated
with vis.gl or the deck.gl maintainers, although it builds on their work: the layer designs,
the WGSL shaders and the projection math are ports of
[deck.gl](https://github.com/visgl/deck.gl) and [luma.gl](https://github.com/visgl/luma.gl).
