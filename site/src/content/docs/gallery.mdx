import { scenes } from '../../scenes.js'

export const url = (path) => `${import.meta.env.BASE_URL.replace(/\/$/, '')}/${path}`
export const image = (name) => url(`images/${name}`)

Every picture here is a JSON description in `examples/json/`, rendered headless with
`cargo run --release --bin json_render -- examples/json/<name>.json out.png`. They are
regenerated from the repository, so they show what the current code draws.

## Over a basemap

These eight are placed at real coordinates. Open one and it runs: the same JSON drawn live
on WebGPU over an [mln-rs](https://github.com/louwers/mln-rs) basemap, sharing one GPU
device and one frame with it, so deck's geometry is hidden where it passes behind the map's
buildings.

## Inside a map

<div class="hero-shot">
  <img
    src={image('maplibre-interleaved.png')}
    alt="deckgl arcs weaving through maplibre-native's 3D buildings"
  />
</div>

Depth interleaved rendering: deckgl arcs and maplibre-native's own extruded buildings
in one frame, sharing a depth buffer, so each arc is hidden where it passes behind a tower and
visible where it clears one. This is maplibre-native's GLFW app on Metal, drawing
`examples/json/maplibre-arcs.json` through the C API. See
<a href={url('docs/maplibre-native/')}>maplibre-native</a>.
